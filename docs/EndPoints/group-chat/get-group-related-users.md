# Group Members & Requests

List active members, blocked members, and pending join requests for a group.

---

## GET /group/:groupId/members/active

Get members who have joined the group.

**Headers**:

- `Authorization: Bearer {{token}}`

**Path Parameters**:

- `groupId` string

**Query Parameters**:

- `page` Optional string/number. Values below `1` or invalid fall back to `1`.
- `limit` Optional string/number. Values below `1` or invalid fall back to `10`.

**Example cURL Request**:

```bash
curl -X GET "{{baseUrl}}/group/67d0f84f0a4f4f49f2a4c111/members/active?page=1&limit=20" \
  -H "Authorization: Bearer {{token}}"
```
